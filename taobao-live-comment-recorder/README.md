# 淘宝直播评论记录器

这是一个无需构建、可直接以“已解压的扩展程序”安装的 Chrome/Edge
Manifest V3 扩展。它只读取淘宝直播中控台页面上已经显示的新评论，不请求淘宝私有接口，
也不会读取或导出登录 Cookie。

## 安装

1. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `taobao-live-comment-recorder` 文件夹。
5. 刷新淘宝直播中控台页面。

## 首次设置

1. 打开自己的直播中控台，并确认“直播互动 → 评论”中能看到评论。
2. 点击右下角记录器的“设置采集区域”。
3. 点击任意一条评论的“昵称（账号）时间”文字行。
4. 再点击同一条评论下一行的正文。
5. 点击“开始记录”。扩展会先导入评论区当前已经加载的历史评论，再持续记录新增评论。

页面改版后如果不再产生记录，重新执行上述区域设置即可。

评论区采用滚动加载时，可以在记录过程中滚动评论列表，让更早的评论加载出来。扩展会用
“昵称/账号 + 页面时间 + 评论正文”持久去重，刷新页面或重复滚动不会重复写入。同一分钟
同一用户发送的完全相同内容也会视为重复评论。

## 自动补采全部历史

点击“补采全部历史”后，扩展会自动操作评论区自己的滚动条：

1. 从当前位置向上逐屏滚动，触发中控台加载更早评论。
2. 连续多次确认到达最早位置后，再向下逐屏扫描至最新位置。
3. 每一屏都会保存尚未记录的评论，已经记录过的评论会被跳过。
4. 扫描过程中按钮会变成“停止补采”，可以随时停止，已采集内容仍会保存。

“历史补采速度”默认选择“慢速稳妥”：每次只移动约半屏，屏与屏之间保留重叠区域，
并至少等待约 2 秒；如果淘宝仍在异步更新评论列表，还会继续等待列表稳定后再采集。
数据量很少时可以改为“标准”，不建议在长直播中使用“快速”。

补采只会滚动评论列表，不会滚动整个中控台页面。淘宝中控台如果已经从服务端删除或限制
展示某些更早评论，扩展无法恢复平台不再提供的内容。

## 导出和隐私

- “导出 CSV”会下载 UTF-8 BOM 编码的 CSV，可直接用 Excel 打开。
- 默认勾选“导出时匿名化昵称”，昵称与账号会生成稳定的短哈希，账号列留空。
- 评论原始记录保存在本机浏览器的扩展存储中，不会上传到第三方服务器。
- “清空记录”只删除当前直播间当前记录会话，操作前会再次确认。

## 使用限制

- 页面未显示、被中控台丢弃或快速滚动时未渲染的评论无法被记录。
- 请只用于已获授权的直播间，并遵守平台规则和个人信息保护要求。
- 不要将包含用户昵称或账号的原始数据公开传播；只保留实现分析目的所需的最短时间。
